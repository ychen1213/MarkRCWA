# MarkRCWA Windows 桌面程序

本程序在 Windows 10/11 x64 上本地运行，用于一维周期结构 RCWA 仿真。现在默认提供纯源码目录，使用公司已有的 Python 和依赖，不包含运行时或冻结 EXE。修改 `src` 中的 `.py` 后重启即可生效，无需打包或安装本项目。使用过程不联网、不需要 WSL 或管理员权限。

## 打开程序

1. 复制完整的源码目录，保留 `run_rcwa.py`、启动脚本和 `src`。双击 `检查环境.bat`，确认选中公司已有的 Python 环境；参考依赖见 `requirements-source.txt`。
2. 双击 `启动RCWA.bat`，或用已有 Python 运行 `python run_rcwa.py`。多个 Python 环境时，可以在启动脚本里指定 `MARKRCWA_PYTHON` 为目标 `python.exe` 完整路径。启动器只检查依赖，不安装或下载。
3. 直接编辑 `src` 内源码，保存、关闭程序、重新启动即可。将工程、材料和计算结果保存在当前账户可写的工作目录。

本仓库提供可直接修改的源码和启动脚本；Python 与依赖由已有环境提供。

交互式 3D 预览导出为 HTML，可用公司允许的本地浏览器打开；绘图脚本已内嵌，不需要联网。程序不修改注册表或系统 PATH，不安装服务。

界面和绘图字体优先使用系统已有中文字体。Matplotlib 缓存及启动诊断写入 `%LOCALAPPDATA%\MarkRCWA`；账户目录不可写时回退到用户临时目录，不写程序目录。程序发生启动错误时会提示诊断日志位置。

## 建模和计算

程序默认打开“工艺与结构”页，顶部两个蓝色按钮是主要建模入口：

- **导入 GDS**：选文件后，直接从下拉框选择 Cell、Layer / Datatype；右侧显示图案、数量、边界及选区。可设置材料、添加或刻蚀、厚度、母周期、选区和横纵偏移。图案在远离原点的位置时，可用“将图形中心移到当前单元中心”。母周期须按设计值确认，不能简单等同于版图包围盒宽度。
- **定义 Mark 图案**：选择普通周期光栅、AH32、AH53、AH74 或自定义多条纹，设置母周期、CD、高度、材料和整体偏移。自定义模式可按条纹中心和宽度增删修改，右侧预览完整母周期。AH 模板沿用 MarkSim：AH32 为 2 条 / P÷3 间距，AH53 为 3 条 / P÷5 间距，AH74 为 4 条 / P÷7 间距。

两个向导底部都有“替换某步骤 / 新增图案步骤”和“同步计算单元”。默认替换现有掩模步骤，避免与示例条纹叠加；其它膜层保留。只有明确勾选同步，才会改变原有周期或选区。应用后自动选中目标步骤并生成几何；取消不会修改工程。二维 GDS 可导入查看真实几何，但不满足 y 不变性时，RCWA 求解仍会拒绝，不自动用任意截面冒充。

1. 新建工程会载入合成光栅，使用顶部两个入口替换示例。也可点击“导入 MarkSim”，选择包含 `project.yaml` 的工程目录；程序只读取材料和工艺，不启动 Meep、不修改原工程。
2. 在“材料”导入 TXT/CSV 或添加常数材料。读取支持 UTF-8、UTF-8 BOM、带 BOM 的 UTF-16/UTF-32 及 GBK/GB18030，导入后显示采用的编码；无法解码时提示另存 UTF-8。导入时明确波长单位、列号；没有 k 时，只有明确勾选无损近似才允许作为实际用材求解。示例 n/k 不代表经过标定的材料数据。
3. 在“工艺与结构”按顺序编辑衬底、添加、刻蚀、删除、表面包覆或填平。选中步骤后编辑表单，应用并生成几何。GDS 掩模需指定 Cell、Layer、Datatype，且实际图形沿 y 不变。
4. 生成几何后可看实际截面和 RCWA 层栈，点击“旋转 3D 视图”打开本地 HTML。半无限衬底的显示厚度不会自动成为有限薄膜。
5. 在“RCWA 设置”选择波长、入射角、TE/TM 和 Fourier 半阶数 N。也可扫描波长、角度，或指定工艺步骤的厚度、横移、CD 偏置、刻蚀深度和侧壁包覆厚度。
6. 单点结果可运行“检查阶数收敛”，逐步提高 N，检查总 R/T、各阶效率、有足够功率的相位，以及每个非零传播反射阶的复振幅相对变化。默认复振幅条件为 `|本档−前档|/|本档| ≤1%`，须连续两次同时满足全部变化条件。幅值 ≤1e-10 的项单列，不声称相对精度通过；跨越该门槛、新增或缺失反射阶会阻止该步通过。最大 N 可自行设置（上限 255）；达到上限仍未通过时显示未收敛。它不检查轮廓切片误差，也不提供真实误差上界。

PH 的梯形、圆角和多边形截面可通过“导入 PH 截面”载入 YAML/JSON；保留原参数截面计算。工艺建模沿用 MarkSim 的 90° 侧壁几何规则。两者不会被隐式互相近似。

工程保存为 `.mrcwa.json`，包含材料数值快照；另存时会把所需 GDS、材料原始文件或色散 CSV 复制到旁边的 `assets` 文件夹。携带工程时应一并复制这些资产。未保存工程的计算默认写入当前用户工作区；保存后的工程将结果写在工程旁边的独立结果目录。关闭或切换工程时，未保存草稿会保存到用户工作区的 `recovery.mrcwa.json`。

每个任务自动生成 **`R_matrix.xlsx`**，包含 `R矩阵`、`复振幅`、`说明` 三个工作表，按波长、入射角、几何扫描值和衍射级 m 列出 `Rss/Rsp/Rps/Rpp` 的复数值、数值实部/虚部、幅值及相位，并包含复振幅幅值与衍射级的图。矩阵行是输出偏振，列是输入偏振。请选择 **TE + TM** 得到两个对角元素；只算单偏振时，另一个对角元素留空并标为未计算。

结果页可填写入射 Jones 分量 `Es_in` 和 `Ep_in`（例如 `1`、`0+1j`，不自动归一化），按 `Es_out=Rss*Es_in+Rsp*Ep_in`、`Ep_out=Rps*Es_in+Rpp*Ep_in` 显示各阶复振幅、幅值和可靠相位。结果页的“导出 Excel”使用当前入射值；任务自动生成的工作簿使用默认单位 s 入射 `(1,0)`。更改入射值只做后处理，不重新求解。Excel 的原始相位与相位可靠标记分别保存，零幅值相位为空。

任务也保留 `input.json`、`manifest.json`、实际几何、材料取值、逐点 `diffraction.json/csv`、`phase_reference.json`，以及汇总 `summary.json/csv` 和 `results.h5`；扫描还会保存 `scan.png`。已有 `summary.json` 可直接加载并导出新格式，无需重算。设置改变后，旧结果会明确标为历史结果。

## 相位和功率

采用 `exp(-iωt)`，材料使用 `n+ik`。建模坐标 z 向上，入射从上方指向衬底；计算层序按深度向下排列。x 相位原点使用模型的物理 x=0，不把单元左边界平移隐去。

反射矩阵沿用 PH 当前固定实验室电场基（s=TE，p=TM），不改变已有复系数的符号或相位。当前一维、各向同性、非圆锥入射下 `Rsp=Rps=0`，并在 Excel 中明确标注为对称性零。若与采用反射局部 `p=k×s` 基的工具比较，应先统一偏振基；该转换会改变 `Rpp` 符号。

入射和反射复系数使用固定的物理 z 参考面：默认取计算单元上边界，也可在设置中指定。高度扫描不会自动把这个参考面移到结构顶面。透射复系数的输出平面为实际进入衬底的界面；每点都记录其绝对 z。刻蚀等扫描若改变输出界面，比较透射相位时应读取该位置。三个平面同时保存在 JSON 和 HDF5 中。

R/T 为入射功率归一化后的净端口功率。对吸收衬底，T 是穿入输出界面的净功率；A 是有限结构的功率残差，不包括无限深衬底最终吸收的全部能量。低功率相位明确标为无效，不使用相位图的外观代替收敛检查。

非锥形计算支持 Rayleigh 截止阶（纵向波数为零）。能直接求解时按零纵向功率处理；遇到奇异内部模时采用双侧波长极限外推。请求波长、采样波长、外推修正和截止阶列表保存在 JSON 的 `cutoff_metadata` 及 HDF5 的对应属性中，便于区分直接求解和极限处理。

与 Lumerical 参考包的全参数对照由 `mark_rcwa.validation.lumerical_benchmark` 执行。开发环境中的逐元素 1% 相对复数差审计结果为：528 个参数点中，默认结果有 272 点全部非零反射元素满足跨软件相对差 ≤1%，256 点至少一项超限。因此不能宣称全量结果已达到 1% 精度。此前采用绝对差 0.002 的检查不能证明小振幅达到 1% 相对精度。完整参考数据和开发审计报告未随此源码运行目录发布。最新审计分别检查有限阶因子分解、实际采样网格、参考自身变化与 PH 增阶变化；同设置复现不替代默认结果的验收。计算接口另提供一维锥形入射 `solve_conical`，支持完整 s/p 耦合矩阵；桌面界面目前仍使用非锥形 TE/TM 设置。

## 首版范围

- 材料、工艺建模及一维截面转换遵循桌面界面的输入限制；3D 显示用于检查结构。
- x 为周期方向，z 为厚度方向，y 方向须保持不变。有限长度线条或沿 y 变化的结构不属于一维模型。
- 首版仿真为 TE/TM 单偏振的正入射或入射面内斜入射。结果以软件实际提供的反射、透射、逐阶效率、复振幅与相位及扫描导出为准。
- 应逐步提高傅里叶阶数，并对需要切片的截面提高切片数，确认结果收敛。计算成功本身不代表已经收敛。
- 桌面界面尚未接入圆锥入射方位角；各向异性、内部 E/H 近场等尚未交付；本程序也不包含光路功能。

相位采用 `exp(-iωt)` 约定。入射与反射使用固定的上方物理 z 参考面，默认取计算单元顶部；透射在各点实际衬底界面取值。三个参考面的物理位置随结果导出，比较不同几何的透射相位时需核对透射参考面位置。

源码运行所需 Meent、NumPy、SciPy、Tk、Matplotlib、Plotly 等组件由公司已有环境提供。项目许可和第三方说明位于 `LICENSE`、`THIRD_PARTY_NOTICES.md`。源码目录不附带第三方二进制或可选 grcwa/S4 求解器；桌面使用 Meent 的 NumPy 后端。
